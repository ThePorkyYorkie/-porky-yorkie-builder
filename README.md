# Porky Yorkie Measurement Builder

GitHub Pages version.

## Files

- index.html
- styles.css
- app.js
- templates.json
- templates/

## Master images

Put approved master PNGs inside the templates folder using exact filenames from templates.json.

Start with these 5:
- templates/long-sleeve-tshirt.png
- templates/jeans.png
- templates/shorts.png
- templates/blazer-sportcoat.png
- templates/workwear-jacket.png

## Use

Open the GitHub Pages URL in Safari:
1. Choose garment type.
2. Fill fields.
3. Export Finished PNG.

## Position Adjust Mode

If text placement is off:
1. Turn on Position Adjust Mode.
2. Drag field labels into the blank spots.
3. Save Text Positions.

Text positions save locally in Safari per device.
